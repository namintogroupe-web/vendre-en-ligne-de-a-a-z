Leçon six : ajouter ton produit sur Chariow, et créer un code promo.

Ajoutons ton produit. Va dans Produits, puis Ajouter un produit.
Écris le titre : ta promesse. Et la description : tes blocs problème, solution, preuves.
Fixe ton prix.
Ajoute le fichier à livrer : ton guide PDF. Il sera envoyé automatiquement après le paiement. Puis publie.

Maintenant, un code promo. Cherche la partie marketing, puis Codes promo.
Choisis un code facile à retenir, par exemple LANCEMENT, et la réduction.
Et mets une vraie date de fin. Tu te souviens du module quatre : une urgence vraie.

Une astuce indispensable : fais un achat test.
Avec un ami, ou un code de test. Tu vérifies le paiement, l'e-mail reçu, et la livraison du fichier. Comme un vrai client.

Une précision importante : les plateformes changent souvent leurs écrans.
Si un bouton n'est pas exactement au même endroit chez toi, cherche le même mot dans le menu. La logique, elle, reste la même.

Pause. Publie ton produit, crée ton code promo, et fais un achat test.

À retenir.
Le titre porte ta promesse, la description tes blocs.
Le fichier est livré automatiquement.
Et un code promo, avec une vraie date de fin.
